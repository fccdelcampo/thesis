# Prolog-GraphRAG: Neuro-Symbolic Question Answering for Education

> Thesis project by Francis Carlo C. Del Campo, John Reniel D. Cruz, and Jenny Ann T. Guyong · BS in Computer Science, University of the Cordilleras · 2025-2026

Prolog-GraphRAG combines **GraphRAG** (graph-based retrieval-augmented generation) with **Prolog** (logic programming) to improve the accuracy and explainability of question answering over educational material. Facts retrieved from knowledge graphs are turned into Prolog and reasoned over symbolically before the final answer is generated by the language model.

The main contribution lives in [`prolog_graphrag_pipeline/`](prolog_graphrag_pipeline). The other top-level folders are baseline pipelines, evaluation code and utilities used to compare against it.

## Overview

Three systems are compared:

| System | Folder | Description |
|---|---|---|
| **Llama 3 8B** | `tuned_pipeline/` | Baseline LLM without retrieval |
| **GraphRAG-only** | `graphrag_pipeline/` | Llama 3 8B with graph-based retrieval |
| **Prolog-GraphRAG** | `prolog_graphrag_pipeline/` | GraphRAG plus Prolog-based symbolic reasoning |

## Pipeline Architecture

The Prolog-GraphRAG pipeline (`prolog_graphrag_pipeline/`) is made up of two stages:

1. **GraphRAG retrieval** (`graphrag/`): extracts entities from the question, encodes them, and retrieves relevant triples from external knowledge sources (KBpedia and Wikidata).
2. **Prolog reasoning** (`prolog/`): converts retrieved knowledge into Prolog facts and rules, runs them through SWI-Prolog via Janus, and produces an explainable derivation that grounds the final LLM answer.

## Getting Started

### Prerequisites

- Python [3.x]
- [SWI-Prolog](https://www.swi-prolog.org/) [version], used through Janus
- Access to Llama 3 8B ([local weights / provider])
- [OpenAI API key], used for GPT-4 judging in the RAGAS evaluation

### Installation

```bash
git clone https://github.com/fccdelcampo/thesis.git
cd thesis
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -r prolog_graphrag_pipeline/requirements.txt
```

## Usage

> Replace the commands below with the actual arguments of your drivers.

```bash
# Run the Prolog-GraphRAG pipeline
python -m prolog_graphrag_pipeline.main_driver [args]

# Run the baselines for comparison
python -m graphrag_pipeline.main_driver [args]
```

## Evaluation

### 1. RAGAS (synthetic QA)
- 100 synthetic QA pairs, judged by GPT-4
- Prolog-GraphRAG vs. GraphRAG-only
- Code: `hallucination_evaluation_pipeline/code/`

### 2. Benchmarks
- **OpenBookQA**, **ARC**, and **MMLU**: 100 questions each (300 total)
- Llama 3 8B vs. GraphRAG-only vs. Prolog-GraphRAG
- Test sets: `test_cases/`

### 3. Calibration (Semantic Entropy)
- Calibration compared across three prompt configurations: question only, question + GraphRAG context, and question + GraphRAG context + Prolog-GraphRAG results
- Test cases drawn from the RAGAS dataset
- Code: `explainability_evaluation_pipeline/code/`

### Statistical analysis
- **RAGAS scores**: two-sided Wilcoxon signed-rank test on per-question scores, with Bonferroni correction
- **Benchmark accuracy**: Cochran's Q test with exact McNemar's tests for pairwise differences
- Code: `hallucination_evaluation_pipeline/stats/`

Results (CSVs and plots) are stored in `hallucination_evaluation_results/` and `explainability_evaluation_results/`.
